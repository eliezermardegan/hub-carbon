# HubCarbon 2026 Capability Benchmark

This benchmark is an architectural planning matrix, not a product ranking.

| Reference | Strong observed capability | HubCarbon response |
|---|---|---|
| Persefoni | Enterprise carbon accounting and integration automation | Carbon Accounting Engine + Integration Plane |
| Watershed | Broad climate management, data, supply chain and reporting workflow | Common Climate Data + Reporting Plane |
| Carbonova | Industrial ingestion across SAP/Oracle/SCADA/IoT with normalization and traceability | Enterprise Integration SDK + Industrial data adapters |
| carbmee | Industrial carbon accounting, Scope 3, LCA/PCF orientation | Product Footprint / Scope 3 extension |
| IBM Envizi | ESG data capture, normalization, hierarchy, quality and auditability | Canonical Climate Data + Evidence/Provenance |
| SAP Sustainability Control Tower | ERP-centered sustainability data and auditable reporting | ERP-neutral integration + Reporting |
| Microsoft Sustainability Manager | Extensible sustainability data model, calculation profiles and calculation data trail | Canonical data model + deterministic calculation traces |
| Normative | Carbon accounting and Scope 1/2/3 reporting | Accounting methodologies and reporting mappings |
| Greenly | Automated accounting, data collection and reporting workflows | Ingestion + calculation + report workflow |
| Sweep | Enterprise climate management and value-chain data | Multi-entity/value-chain model |
| Salesforce Net Zero Cloud | CRM/workflow/AI-oriented sustainability management | Workflow APIs + controlled AI assistance |

## Target differentiation

HubCarbon adds capabilities that must be first-class rather than bolt-ons:

1. Evidence and provenance as domain primitives.
2. Replayable audit/event ledger.
3. Methodology-as-code with explicit versioning.
4. Regulatory Intelligence as a governed rule plane.
5. dMRV as a native engine.
6. CDR/project lifecycle and mitigation-outcome workflows.
7. DLT-neutral trust interfaces.
8. Vendor-neutral enterprise integration.
